[size=5][b]RDR2 Controller Rumble[/b][/size] - v1.8.0
[i]Rumble that follows what happens in the game - for DualSense and Xbox controllers. (Formerly "RDR2 DSX Rumble".)[/i]

[b]30+ rumble effects, each one fine-tuned by hand[/b] - plus [b]12 adaptive trigger profiles[/b] for the weapons on the DualSense.

[b]DualSense users: use [url=https://store.steampowered.com/app/1812620/DSX/]DSX[/url], or the new DualSense Native file without DSX (see Alternative installation).[/b] Both give you adaptive triggers and the lightbar. Xbox controllers work without anything extra.

[size=4][b]What's new in v1.8.0[/b][/size]
[list]
[*][b]Footsteps dropdown in F11:[/b] switch footsteps off, set their strength, and turn them on or off for walking, running and sprinting on their own
[*]Walking no longer rumbles by default, on foot and on horseback (switch it back on in the F11 dropdowns)
[*]The Advanced settings page is more compact
[*][b]New optional file: DualSense Native[/b] - DualSense without DSX, with PlayStation buttons (see Alternative installation)
[/list]

[size=4][b]Features[/b][/size]
[list]
[*][b]Footsteps[/b] - one tap per real step
[*][b]Horse[/b] - hoofbeats that follow the gait, jumps, crashes, deep snow
[*][b]Guns[/b] - a kick sized to each weapon, reload and weapon-switch clicks
[*][b]Fights and damage[/b] - punches given and taken, wounds, animal attacks
[*][b]World[/b] - water, swimming, doors, carrying bodies, eating and items, sliding, falls, wagons, cutscenes
[*][b]Low health[/b] - a heartbeat
[*][b]DualSense only:[/b] adaptive triggers tuned per weapon (plus bow and lasso), lightbar that changes with the place you are in and turns red in fights
[/list]

[size=4][b]Requirements[/b][/size]
[list]
[*][url=https://www.dev-c.com/rdr2/scripthookrdr2/]Script Hook RDR2[/url]
[*]DualSense with [url=https://store.steampowered.com/app/1812620/DSX/]DSX[/url], or DualSense without DSX (DualSense Native file), or an Xbox controller
[*]Alternative (DualSense Native file only): [url=https://www.rdr2mods.com/downloads/rdr2/tools/76-lennys-mod-loader-rdr/]Lenny's Mod Loader[/url], needed for the PlayStation buttons
[/list]

[size=4][b]Installation[/b][/size]
[list=1]
[*]Install Script Hook RDR2.
[*]Copy [i]RDR2DSXRumble.asi[/i] and [i]RDR2DSXRumble.ini[/i] into the game folder (next to [i]RDR2.exe[/i]).
[*]DualSense with DSX: in DSX turn on [b]Incoming UDP[/b] (Settings > Networking) and turn [b]Rumble to Haptics OFF[/b]. Start DSX before the game.
[/list]

[size=4][b]Alternative installation: DualSense without DSX (experimental)[/b][/size]
Optional file [i]DualSense Native (no DSX)[/i]. The mod talks to the DualSense itself: same rumble, adaptive triggers and lightbar.
[list=1]
[*]Install Script Hook RDR2.
[*]Copy [i]RDR2DSXRumble.asi[/i] and [i]RDR2DSXRumble.ini[/i] from the DualSense Native zip into the game folder.
[*][b]PlayStation buttons:[/b] install [url=https://www.rdr2mods.com/downloads/rdr2/tools/76-lennys-mod-loader-rdr/]Lenny's Mod Loader[/url] and copy the [i]lml[/i] folder from the zip into the game folder.
[*]Steam: RDR2 > Properties > Controller > Steam Input [b]ON[/b]. Keep DSX closed.
[/list]

[size=4][b]Settings[/b][/size]
Press [b]F11[/b] in game. Everything else is in [i]RDR2DSXRumble.ini[/i] (changes apply while the game runs).

[size=4][b]Troubleshooting[/b][/size]
[list]
[*][b]No rumble:[/b] DualSense with DSX - check DSX is running with Incoming UDP on. DualSense Native - check DSX is closed and Steam Input is ON. Then check [i]RDR2DSXRumble.log[/i] in the game folder.
[*][b]Weak rumble on DualSense:[/b] turn off "Rumble to Haptics" in DSX.
[*][b]Double rumble or fighting triggers:[/b] disable other vibration/DualSense mods.
[*]Story mode only.
[/list]
