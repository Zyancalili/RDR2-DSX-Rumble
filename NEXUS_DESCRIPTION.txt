[size=5][b]RDR2 Controller Rumble[/b][/size] - v1.8.2
[i]Rumble that follows what happens in the game, for DualSense and Xbox controllers. (Formerly "RDR2 DSX Rumble".)[/i]

[b]30+ rumble effects[/b], each one tuned by hand, plus [b]12 adaptive trigger profiles[/b] for the weapons on the DualSense.

[line]

[size=4][b]Which file do I need?[/b][/size]
[list]
[*][b]Xbox controller[/b] - main file
[*][b]DualSense with DSX[/b] - main file
[*][b]DualSense without DSX[/b] - optional file [i]DualSense Native (no DSX)[/i], experimental
[/list]

[line]

[size=4][b]What's new in v1.8.2[/b][/size]
[list]
[*][b]Rumble stays on with DSX:[/b] if reading the controller fails, only the F11 menu buttons stop, and if DSX's virtual controller stops taking rumble, the mod switches to the Xbox route instead of trying it again and again
[*][b]Bluetooth fix for the DualSense Native file[/b] (from v1.8.1)
[*]If you still get no rumble over Bluetooth, please post your [i]RDR2DSXRumble.log[/i]
[/list]

[line]

[size=4][b]Features[/b][/size]
[list]
[*][b]Footsteps[/b] - one tap per real step
[*][b]Horse[/b] - hoofbeats that follow the gait, jumps, crashes, deep snow
[*][b]Guns[/b] - a kick sized to each weapon, reload and weapon-switch clicks
[*][b]Fights and damage[/b] - punches given and taken, wounds, animal attacks
[*][b]World[/b] - water, swimming, doors, carrying bodies, eating and items, sliding, falls, wagons, cutscenes
[*][b]Low health[/b] - a heartbeat
[*][b]DualSense only[/b] - adaptive triggers per weapon (plus bow and lasso), and a lightbar that changes with the place you are in and turns red in fights
[/list]

[size=4][b]Requirements[/b][/size]
[list]

[line]

[size=4][b]Installation: main file (Xbox, or DualSense with DSX)[/b][/size]
[list=1]
[*]Install Script Hook RDR2.
[*]Copy [i]RDR2DSXRumble.asi[/i] and [i]RDR2DSXRumble.ini[/i] into the game folder (next to [i]RDR2.exe[/i]).
[*][b]DualSense only:[/b] in DSX turn [b]Incoming UDP on[/b] (Settings > Networking) and [b]Rumble to Haptics off[/b]. Start DSX before the game.
[/list]

[size=4][b]Installation: DualSense Native (no DSX)[/b][/size]
[list=1]
[*]Install Script Hook RDR2.
[*]Copy [i]RDR2DSXRumble.asi[/i] and [i]RDR2DSXRumble.ini[/i] into the game folder.
[*]For PlayStation buttons: install Lenny's Mod Loader, then copy the [i]lml[/i] folder from the zip into the game folder.
[*]In Steam: RDR2 > Properties > Controller > Steam Input [b]on[/b]. Keep DSX closed.
[/list]

[line]

[size=4][b]Settings[/b][/size]
Press [b]F11[/b] in game.
More options are in [i]RDR2DSXRumble.ini[/i]. Changes apply while the game runs.

[line]

[size=4][b]Troubleshooting[/b][/size]
[list]
[*][b]No rumble with DSX:[/b] check that DSX is running with Incoming UDP on.
[*][b]No rumble with Native:[/b] check that DSX is closed and Steam Input is on.
[*][b]No rumble over Bluetooth with DSX:[/b] check that "Rumble to Haptics" is off in DSX.
[*][b]Still nothing:[/b] look at [i]RDR2DSXRumble.log[/i] in the game folder.
[*][b]Weak rumble on DualSense:[/b] turn off "Rumble to Haptics" in DSX.
[*][b]Double rumble or fighting triggers:[/b] disable other vibration or DualSense mods.
[*]Story mode only.
[/list]
